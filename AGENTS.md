# AGENTS.md local do projeto

Este arquivo registra instrucoes especificas para o repositorio
`radar-transicao-energetica`.

## Implementacao neste projeto

Neste projeto, implementacoes nao dependem do comando `ps`.

Quando o usuario pedir uma alteracao, revisao com melhoria, implementacao,
geracao de codigo, documentacao, testes, build ou empacotamento, o agente pode
executar diretamente a tarefa dentro do escopo solicitado, respeitando o estado
do repositorio, os criterios de aceite e as validacoes cabiveis.

O comando `ps` pode continuar sendo usado pelo usuario como sinal explicito de
prosseguimento, mas nao e um pre-requisito para implementar neste repositorio.

## Escopo desta regra

Esta regra vale apenas para este repositorio local e nao altera o `AGENTS.md`
global do Codex Desktop.
